# 广告地狱 · 净网行动

一个单文件的复古网页风点击小游戏。你只想安安静静看部电影，但弹窗广告会自我增殖，且关闭方式各不相同。在耐心耗尽前清掉 24 个广告，才能看到电影。

- 纯前端，零依赖，无需构建
- 单文件实现：`index.html`（HTML + CSS + 原生 JS）
- 适配桌面与移动端（长按 / 滑块使用 Pointer Events）

---

## 快速开始

直接用浏览器打开 `index.html` 即可。

```bash
# Windows
start index.html

# macOS
open index.html

# 或起一个本地静态服务（可选）
python -m http.server 8000
```

无需 `npm install`，无打包步骤，无外部资源请求。

## 玩法规则

1. 点击「开始上网」后进入游戏，屏幕上会不断弹出广告窗口。
2. 用对应方式关闭广告，进度 `+1`（可被强化加成）。
3. 每关闭 **3 个广告**，暂停游戏并弹出**三选一强化**，强化可叠加。
4. 广告会随时间**自我增殖**：场上广告越多，耐心掉得越快；拖延只会更糟。
5. 顶部「耐心度」归零 → 失败；「净化进度」达到 `24/24` → 胜利。
6. 结算界面可一键重开，状态完全重置。

### 界面元素

| 元素 | 位置 | 说明 |
| --- | --- | --- |
| TIME CLOCK | 左上 | 本局已用时间，`mm:ss` |
| 耐心度 | 中上 | 当前值 / 上限，颜色随比例由绿变红 |
| 净化进度 | 右上 | 已关闭广告数 / 目标数（24） |
| 广告窗口 | 屏幕内 | 位置、尺寸、题材均随机 |

## 广告类型与关闭机制

| 类型 | 出现概率 | 关闭方式 | 细节 |
| --- | --- | --- | --- |
| `basic` 普通 | 42% | 点击 ✕ | 无额外限制 |
| `runner` 逃跑 | 16% | 追着点 ✕ | 鼠标靠近瞬移，共躲 4 次后累瘫（闪烁提示） |
| `countdown` 倒计时 | 15% | 等待 3 秒后点击 ✕ | 期间按钮禁用并显示剩余秒数 |
| `hold` 长按 | 14% | 按住 ✕ 不放 | 默认 0.9 秒，按钮内绿色进度条指示 |
| `slider` 滑块 | 13% | 拖动滑块到最右 | 需拖到 ≥98.5%，中途松手会回弹归零 |

所有类型的 ✕ 尺寸都会受「钛合金鼠标」强化影响。

## 强化（Buff）一览

关闭广告累计次数达到 3 的倍数时，从**未满级**的强化中随机抽 3 个供选择，选择后立即生效并叠加。

| 强化 | 图标 | 上限 | 效果 | 实际数值 |
| --- | --- | --- | --- | --- |
| 精神胜利法 | 🧘 | 6 | 每次关闭广告恢复耐心 | `+6` / 层 |
| 效率至上 | ⚡ | 3 | 每次关闭额外增加进度 | `+1` / 层 |
| 多米诺骨牌 | 🎯 | 3 | 关闭时概率连带关闭另一个 | `+30%` / 层（最高 90%） |
| 弹窗拦截器 | 🛡️ | 3 | 广告增殖速度降低 | 增殖间隔 `×1.34` / 层（约 -25% 频率） |
| 静音模式 | 🔇 | 2 | 耐心基础消耗降低 | `×0.60` / 层（最高 -64%） |
| 钛合金鼠标 | 🖱️ | 3 | 关闭按钮尺寸增大 | `+40%` / 层 |
| 连点器 | ⏱️ | 2 | 长按所需时间减少 | `×0.65` / 层 |
| 续命咖啡 | ☕ | 2 | 耐心上限提升并回满 | `+30` 上限 / 层 |
| 自动拦截 | 🤖 | 2 | 定时自动关闭随机广告 | 间隔 `9s / 层`（2 层即 4.5s） |

设计上可组合出「回复流」「连锁流」「挂机流」等不同打法。

## 数值模型

### 耐心消耗

每秒扣减：

```
drain = (0.15 × baseDrainMul + 场上广告数 × 0.13) × dt
```

即空场每秒 -0.15，每个在场广告额外每秒 -0.13。9 个广告时约每秒 -1.32。

### 广告增殖

每个广告各自带一个增殖计时器，到期后尝试生成新广告：

```
breedT = (10 + random × 5) × spawnMul × pressure
pressure = 1 - (progress / target) × 0.35
```

- `spawnMul` 每层「弹窗拦截器」乘 `1.34`
- 进度越高，`pressure` 越小，增殖越慢（最低 0.65 倍）
- 场上为空时，会以 1 秒的间隔自动补一个广告

### 关闭奖励

```
progress += 1 + extraProgress
closes   += 1
patience  = min(maxPatience, patience + patiencePerClose)
```

- 进度达到 24 立即判定胜利
- `closes % 3 === 0` 且未暂停时触发三选一

### 主循环

基于 `requestAnimationFrame`，单帧 `dt` 上限 `0.05s`（防止切后台后大跳变）。暂停时（如三选一弹窗）`update` 直接返回，广告计时器与耐心消耗全部冻结。

## 扩展指南

### 新增一种广告素材

在 `THEMES` 数组中追加对象即可，无需改逻辑：

```js
{ title:'标题栏文字', html:`<div>...广告内容...</div>` }
```

### 新增一种关闭方式

1. 在 `pickType()` 的概率区间中加入新类型（注意各分支概率总和为 1）。
2. 在 `setupClose()` 的 `switch(type)` 中新增 `case`，在合适时机调用 `closeAd(ad)`。
3. 若需要逐帧更新，把函数赋给 `ad.tick = (dt) => {...}`；完成后置为 `null`。

### 新增一个强化

在 `BUFFS` 中追加：

```js
{ id:'xxx', name:'名称', icon:'✨', max:2,
  desc:'说明文案（会显示在卡片上）',
  apply:s => { /* 修改 s / s.buffs */ } }
```

若引入新的可叠加字段，需同步在 `state` 与 `resetState()` 的 `buffs` 初始化中加入，否则重开会残留旧值。

## 已知限制

- 无音效、无存档、无排行榜；刷新即重开。
- 「逃跑」广告依赖 `mouseenter`，触屏设备上不会闪避，可直接点击。
- 全部状态挂在单一 `state` 对象上，无模块拆分，仅适合单文件小游戏规模。
- 广告素材为内联 HTML 字符串，无 CSP 与转义处理；新增素材时不要引入外部脚本。
